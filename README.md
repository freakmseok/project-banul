# 바늘공주Forest Kim — 채널 소개 홈페이지

유튜브 채널 **바늘공주Forest Kim** ([@forestkim3588](https://www.youtube.com/@forestkim3588))의 소개 페이지입니다.
별도 빌드 없이 `index.html` 한 파일로 동작하는 정적 사이트입니다.

## 실행 방법

```bash
# 그대로 파일 열기
index.html   # 브라우저로 열기

# 또는 로컬 서버로
python3 -m http.server 8080
# http://localhost:8080
```

> 썸네일(ytimg), 임베드(youtube-nocookie), 웹폰트(Google Fonts · Pretendard)를 불러오므로 인터넷 연결이 필요합니다.

## 페이지 구성

| 섹션 | 내용 |
| --- | --- |
| Hero | 채널 타이틀, 니트 텍스처 배경, 구독 CTA |
| Marquee | 코바늘 · 대바늘 · 수초가꾸기 등 키워드 띠 |
| 소개 | 채널 소개문, 손뜨개 / 물생활 2단 카드, 채널 정보 카드 |
| 통계 | 구독자 · 업로드 수 · 최근 1년 신작 · 채널 시작 (스크롤 카운트업) |
| 영상 | 최신작 피처 카드 + **최신 / 인기 탭** (각 6편, 겹치는 영상 없음), 카드 클릭 시 페이지 내 라이트박스 플레이어 |
| 카테고리 | 손뜨개 · 겨울가디건 · 가방뜨기 · 물생활 재생목록 |
| 도안·패키지 | 네이버 도안 / 패키지 / 밴드 커뮤니티 / Ravelry 영어 도안 |
| 구독 | 구독 CTA · 푸터 링크 |

## 기술 스택

- 순수 **HTML + CSS + vanilla JavaScript** (외부 라이브러리 없음)
- SVG 기반 니트 텍스처 · 실 ball · 바늘 그래픽
- `IntersectionObserver` 스크롤 등장 / 숫자 카운트업 (미지원 브라우저 자동 대체)
- 영상 팝업: 유튜브 nocookie 임베드 + 차단 환경용 "유튜브에서 열기" 폴백
- `prefers-reduced-motion` 대응, 모바일 반응형, 키보드 접근성(탭 방향키 · ESC)

## 데이터 출처

| 구분 | 출처 | 기준 |
| --- | --- | --- |
| 최신 영상 탭 | 유튜브 공식 RSS 피드 (`feeds/videos.xml`) | 공개일 내림차순, 정확한 공개일·조회수 |
| 인기 영상 탭 | 유튜브 채널 영상 탭의 **인기순 정렬** | 채널 전체 영상 중 조회수 상위 6편 |
| 피처 카드 | 최신 업로드 1편 | 공개일 · 조회수 · 좋아요 수 |

브라우저에서 유튜브 API를 직접 호출하면 CORS로 막히기 때문에, 두 목록은 빌드 시점에 실제 데이터를 받아 정적으로 넣어 둡니다 (2026-09 수집).
구독자 수 등 수치는 변동될 수 있습니다.
